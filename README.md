# Mi año en Creamos

Prototipo de la Línea de Base Intermedia (C_02.2) de Creamos: una pregunta por pantalla, para celular o compu.

- Formulario: `index.html`
- Pantalla del salón: `index.html#pantalla`

Es un prototipo para Adrián. En esta versión las respuestas se guardan solo en el navegador que se use, y la pantalla del salón se actualiza si está abierta en otra pestaña del mismo navegador. La conexión con Ora está descrita en «Notas para Adrián», al inicio del formulario.
